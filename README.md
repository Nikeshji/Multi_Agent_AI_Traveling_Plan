✈️ AI Travel Booking System
🤖 Real-World Multi-Agent AI System built with LangGraph

✨ Features

| Feature                          | Description                                          |
| -------------------------------- | ---------------------------------------------------- |
| ✈️ **Flight Search Agent**       | Searches real-time flights using AviationStack API   |
| 🏨 **Hotel Search Agent**        | Finds best hotels & attractions via Tavily Search    |
| 🗓️ **Itinerary Planning Agent** | Creates detailed day-by-day travel plans             |
| 🧠 **Final Response Agent**      | Combines everything into a beautiful travel report   |
| 🧠 **AI Memory**                 | PostgreSQL-backed conversation memory with LangGraph |
| 🌐 **Real-time APIs**            | Live flight & hotel data integration                 |
| 💻 **3D Web Dashboard**          | Futuristic glassmorphism UI built with Streamlit     |
| 📥 **Download Plans**            | Export your travel plan as Markdown                  |

🛠️ Tech Stack
| Technology            | Purpose                                       |
| --------------------- | --------------------------------------------- |
| **LangGraph**         | Multi-agent workflow orchestration            |
| **LangChain**         | LLM chaining & tool binding                   |
| **Groq**              | Ultra-fast LLM inference (LLaMA 3.3 70B)      |
| **Streamlit**         | Interactive web dashboard                     |
| **PostgreSQL**        | Persistent conversation memory                |
| **Tavily API**        | Real-time web search for hotels & attractions |
| **AviationStack API** | Live flight data & schedules                  |

🚀 Quick Start
Prerequisites
Python 3.10+
PostgreSQL (optional — falls back to in-memory)
API Keys: Groq | Tavily | AviationStack
